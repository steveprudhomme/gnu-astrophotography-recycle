# Figures de l’étude ciblée — droits et description

Steve Prud’Homme autorise ces dérivés de ses seize FITS publics, sous **CC0-1.0**, le 18 novembre 2026.
Le code de calcul reste GPL-3.0-or-later. Les catalogues tiers ne sont pas couverts par cette dédicace.

Les montages et extraits sont des images réelles. Les lignes et graphiques sont calculés. `workflow.png` est un schéma.
Ce ne sont pas des captures d’écran. Aucun pixel FITS n’a été réécrit.
Le contraste utilise des percentiles ; les annotations ne représentent pas des détections pixel par pixel.
